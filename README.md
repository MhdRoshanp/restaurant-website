# 🍽️ LeadGen Restaurant Website

A modern and elegant responsive restaurant website built using HTML, CSS, and JavaScript. The website showcases the restaurant, menu, food gallery, chef, blog, contact information, and table booking functionality.

## ✨ Features

- 🏠 Home / Hero Section
- 📖 About Restaurant
- 🍴 Restaurant Services
- 📋 Interactive Menu
- 🖼️ Food Gallery
- 👨‍🍳 Chef Section
- 📰 Restaurant Blog
- 📞 Contact Information
- 🪑 Table Booking Form
- 📱 Responsive Design
- ⚡ Dynamic Menu Categories
- 🔄 Smooth Scrolling Navigation
- 🎨 Hover Effects and Transitions

## 📋 Menu Categories

The interactive menu includes:

- 🥗 Starters
- 🥩 Meat
- 🐟 Fish
- 🥬 Vegetarian
- 🍰 Dessert
- 🥤 Drinks

Menu items, descriptions, and prices are dynamically updated using JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- SVG Icons
- CSS Grid
- CSS Flexbox

### Fonts

- Playfair Display
- Lato

## 🏠 Home Section

The hero section introduces the restaurant with a large background image, a "Delicious Breakfast" heading, restaurant description, and a button to explore the menu.

## 📖 About Section

The About section presents the restaurant's dining experience and culinary approach, highlighting quality ingredients and professional chefs.

## 🍴 Services

The website showcases three main dining services:

- Lunch
- Dinner
- Drinks

Each service contains an icon, title, and description.

## 📋 Interactive Menu

The menu uses JavaScript to dynamically display dishes based on the selected category without reloading the page.

Available categories include:

- Starters
- Meat
- Fish
- Vegetarian
- Dessert
- Drinks

## 🖼️ Food Gallery

A responsive gallery displays different food and restaurant images in a structured grid layout.

## 👨‍🍳 Chef Section

A dedicated section introduces the executive chef along with their experience and culinary philosophy.

## 📰 Blog Section

The website includes a blog section featuring food-related articles and stories with images, titles, and descriptions.

## 📞 Contact & Booking

The contact section provides:

- Restaurant address
- Phone numbers
- Email addresses
- Opening hours
- Table booking form

The booking form collects the customer's name, email, and message and provides a booking confirmation.

## 📱 Responsive Design

The website is designed to work across different screen sizes, including:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

The layout automatically adapts using CSS media queries.

## ⚡ JavaScript Functionality

JavaScript is used for:

- Dynamic menu switching
- Table booking validation
- Booking confirmation
- Smooth scrolling navigation

## 🚀 How to Run

### 1. Clone the Repository

    git clone https://github.com/your-username/restaurant-website.git

### 2. Open the Project

    cd restaurant-website

### 3. Run the Website

Open `index.html` in your browser.

You can also use **Live Server** in Visual Studio Code for development.

## 🌍 Deployment

This static website can be deployed using:

- GitHub Pages
- Netlify
- Vercel
- Any static web hosting service

## 📌 Project Purpose

This project was created to demonstrate the development of a complete restaurant website using **HTML, CSS, and JavaScript**, focusing on responsive design, visual presentation, interactive menus, and table booking.
